# 快速开始指南

## 前置准备

### 1. 环境要求
- Python 3.10+
- Node.js 18+
- Docker & Docker Compose
- PostgreSQL 16
- Redis 7

### 2. 获取豆包 API Key

1. 访问：https://console.volcengine.com/ark
2. 注册/登录账号
3. 创建推理接入点
4. 复制 API Key

## 快速启动（Docker）

### 1. 克隆项目

```bash
git clone https://github.com/your-repo/DutyWise.git
cd DutyWise
```

### 2. 配置环境变量

```bash
cp .env.example .env
vim .env
```

编辑 `.env` 文件：

```bash
# 豆包配置
DOUBAO_API_KEY=your_api_key_here

# 数据库配置
DATABASE_URL=postgresql://postgres:password@postgres:5432/customs_db
REDIS_URL=redis://redis:6379/0

# 爬虫配置
CRAWLER_USERNAME=13825269170
CRAWLER_PASSWORD=201402

# 文件存储
UPLOAD_DIR=/data/uploads
OUTPUT_DIR=/data/outputs
```

### 3. 启动服务

```bash
docker-compose up -d
```

### 4. 初始化数据库

```bash
docker-compose exec backend python -m app.db.init
```

### 5. 访问系统

- 前端：http://localhost:3000
- 后端API：http://localhost:8000
- API文档：http://localhost:8000/docs

## 本地开发（不使用Docker）

### 1. 安装后端依赖

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. 安装 Playwright 浏览器

```bash
playwright install chromium
```

### 3. 启动 PostgreSQL 和 Redis

```bash
# 使用 Docker
docker run -d --name postgres -p 5432:5432 \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=customs_db \
  postgres:16

docker run -d --name redis -p 6379:6379 redis:7
```

### 4. 初始化数据库

```bash
python -m app.db.init
```

### 5. 启动后端服务

```bash
# 启动 API 服务
uvicorn app.main:app --reload --port 8000

# 启动 Celery Worker（新终端）
celery -A app.celery worker --loglevel=info
```

### 6. 安装前端依赖

```bash
cd frontend
npm install
```

### 7. 启动前端服务

```bash
npm run dev
```

访问：http://localhost:3000

## 测试系统

### 1. 准备测试数据

将测试用的 Excel 文件放到 `test_data/` 目录：

```

├── 04.03装柜信息(1).xlsx
├── ZIMUSNH21275749--04.21.xls
└── OTPU6370404清单.xlsx
```

### 2. 运行测试

```bash
cd backend
pytest tests/ -v
```

### 3. 手动测试

#### 使用 Web 界面

1. 打开 http://localhost:3000
2. 点击"上传文件"
3. 选择测试数据（2-3个Excel文件）
4. 点击"开始处理"
5. 等待处理完成
6. 下载结果文件

#### 使用 API

```bash
# 1. 上传文件
curl -X POST http://localhost:8000/api/v1/shipments/upload \
  -F "files=@test_data/04.03装柜信息(1).xlsx" \
  -F "files=@test_data/ZIMUSNH21275749--04.21.xls"

# {
#   "code": 200,
#   "data": {
#     "shipment_id": 1,
#     "task_id": "abc123"
#   }
# }
```

## 常见问题

### Q1: 豆包 API 调用失败

**错误**：`401 Unauthorized`

**解决**：
1. 检查 API Key 是否正确
2. 检查 API Key 是否过期
3. 检查账户余额是否充足

### Q2: 爬虫无法登录

**错误**：`Login failed`

**解决**：
1. 检查账号密码是否正确
2. 检查网站是否更新了登录流程
3. 尝试手动登录一次，看是否需要验证码

### Q3: Excel 解析失败

**错误**：`File parsing error`

**解决**：
1. 检查文件是否损坏
2. 检查文件是否有密码保护
3. 尝试用 Excel 打开并另存为新文件

### Q4: 字段映射不准确

**解决**：
1. 检查豆包 API 是否正常
2. 调整 prompt 提示词
3. 增加训练样本
4. 使用规则匹配作为补充

### Q5: 处理速度慢

**优化**：
1. 启用 Redis 缓存
2. 增加 Celery Worker 数量
3. 使用批量处理
4. 优化数据库查询

## 开发工具推荐

### 1. API 测试

- **Postman**：图形化API测试
- **HTTPie**：命令行API测试
- **Swagger UI**：自动生成的API文档（http://localhost:8000/docs）

### 2. 数据库管理

- **DBeaver**：通用数据库客户端
- **pgAdmin**：PostgreSQL专用客户端
- **Redis Commander**：Redis可视化工具

### 3. 日志查看

```bash
# 查看所有服务日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f backend
docker-compose logs -f celery

# 查看实时日志
tail -f logs/app.log
```

### 4. 性能监控

```bash
# 安装 Flower（Celery监控）
pip install flower

# 启动 Flower
celery -A app.celery flower --port=5555

# 访问：http://localhost:5555
```
