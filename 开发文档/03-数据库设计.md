# 数据库设计

## 3.2 数据表设计

### 3.2.1 shipments（票据表）

```sql
CREATE TABLE shipments (
    id SERIAL PRIMARY KEY,
    shipment_no VARCHAR(100) UNIQUE,          -- 票号
    user_id INTEGER,                          -- 用户ID
    status VARCHAR(20),                       -- 状态：processing/completed/failed
    created_at TIMESTAMP DEFAULT NOW(),
    completed_at TIMESTAMP,

    -- 统计信息
    total_items INTEGER,                      -- 商品总数
    total_weight DECIMAL(10, 2),             -- 总重量
    total_volume DECIMAL(10, 2),             -- 总体积

    -- 文件路径
    input_files JSONB,                        -- 输入文件列表
    output_file VARCHAR(255),                 -- 输出文件路径
    log_file VARCHAR(255),                    -- 日志文件路径

    -- 优化结果
    optimization_count INTEGER DEFAULT 0,     -- 优化数量
    tax_saved DECIMAL(10, 2),                -- 节省税金（估算）

    INDEX idx_shipment_no (shipment_no),
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at)
);
```

### 3.2.2 items（商品表）

```sql
CREATE TABLE items (
    id SERIAL PRIMARY KEY,
    shipment_id INTEGER REFERENCES shipments(id),

    -- 原始数据
    original_name_cn VARCHAR(255),
    original_name_en VARCHAR(255),
    original_hs_code VARCHAR(20),
    original_tax_rate VARCHAR(20),

    -- 优化后数据
    optimized_hs_code VARCHAR(20),
    optimized_tax_rate VARCHAR(20),

    -- 商品属性
    material VARCHAR(100),
    usage VARCHAR(100),
    quantity INTEGER,
    unit VARCHAR(20),
    net_weight DECIMAL(10, 2),
    gross_weight DECIMAL(10, 2),
    cartons INTEGER,
    volume DECIMAL(10, 2),

    -- 优化信息
    is_optimized BOOLEAN DEFAULT FALSE,
    similarity_score DECIMAL(3, 2),
    risk_level VARCHAR(20),                   -- LOW/MEDIUM/HIGH
    risk_warnings TEXT[],

    -- 元数据
    source_file VARCHAR(255),
    created_at TIMESTAMP DEFAULT NOW(),

    INDEX idx_shipment_id (shipment_id),
    INDEX idx_original_hs_code (original_hs_code),
    INDEX idx_optimized_hs_code (optimized_hs_code)
);
```

### 3.2.3 tax_rates（税率缓存表）

```sql
CREATE TABLE tax_rates (
    id SERIAL PRIMARY KEY,
    hs_code_cn VARCHAR(20),
    hs_code_us VARCHAR(20),
    description_cn TEXT,
    description_en TEXT,
    tax_rate VARCHAR(20),
    tariff VARCHAR(20),
    anti_dumping BOOLEAN,
    certification_required BOOLEAN,
    export_tax_refund VARCHAR(20),

    -- 缓存信息
    search_term VARCHAR(255),                 -- 搜索关键词
    cached_at TIMESTAMP DEFAULT NOW(),
    expires_at TIMESTAMP,

    INDEX idx_hs_code_cn (hs_code_cn),
    INDEX idx_search_term (search_term),
    INDEX idx_expires_at (expires_at)
);
```

### 3.2.4 optimization_logs（优化日志表）

```sql
CREATE TABLE optimization_logs (
    id SERIAL PRIMARY KEY,
    shipment_id INTEGER REFERENCES shipments(id),
    item_id INTEGER REFERENCES items(id),

    log_type VARCHAR(20),                     -- optimization/conflict/mapping

    -- 优化日志
    original_hs_code VARCHAR(20),
    new_hs_code VARCHAR(20),
    original_tax_rate VARCHAR(20),
    new_tax_rate VARCHAR(20),
    reason TEXT,
    risk_warning TEXT,

    -- 冲突日志
    conflict_field VARCHAR(50),
    conflict_values JSONB,
    resolution VARCHAR(50),

    -- 映射日志
    source_field VARCHAR(100),
    target_field VARCHAR(100),
    confidence DECIMAL(3, 2),
    mapping_method VARCHAR(50),

    created_at TIMESTAMP DEFAULT NOW(),

    INDEX idx_shipment_id (shipment_id),
    INDEX idx_log_type (log_type)
);
```

### 3.2.5 users（用户表）

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE,
    password_hash VARCHAR(255),

    -- 统计信息
    total_shipments INTEGER DEFAULT 0,
    total_optimizations INTEGER DEFAULT 0,

    created_at TIMESTAMP DEFAULT NOW(),
    last_login_at TIMESTAMP,

    INDEX idx_username (username),
    INDEX idx_email (email)
);
```

## 3.3 Redis 数据结构

### 3.3.1 税率缓存
```
Key: tax_rate:{search_term}
Type: String (JSON)
TTL: 7 days
Value: {
    "results": [...],
    "cached_at": "2026-04-24T10:00:00"
}
```

### 3.3.2 任务状态
```
Key: task:{task_id}
Type: Hash
TTL: 24 hours
Fields:
    - status: processing/completed/failed
    - progress: 0-100
    - current_step: "解析文档"/"查询税率"等
    - error_message: 错误信息（如果失败）
```

### 3.3.3 会话数据
```
Key: session:{session_id}
Type: String (JSON)
TTL: 2 hours
Value: {
    "user_id": 123,
    "uploaded_files": [...],
    "shipment_id": 456
}
```

## 3.4 数据流转

```
1. 用户上传文件
   ↓
   存储到文件系统
   ↓
   创建 shipments 记录（status=processing）

2. 解析文档
   ↓
   创建 items 记录（原始数据）

3. 查询税率
   ↓
   先查 Redis 缓存
   ↓
   未命中则爬取网站
   ↓
   写入 Redis 和 tax_rates 表

4. 优化HS编码
   ↓
   更新 items 记录（优化后数据）
   ↓
   创建 optimization_logs 记录

5. 生成文件
   ↓
   更新 shipments 记录（output_file, status=completed）

6. 用户下载
   ↓
   记录下载日志
```

## 3.5 查询示例

### 3.5.1 获取票据详情
```sql
SELECT
    s.*,
    COUNT(i.id) as item_count,
    SUM(CASE WHEN i.is_optimized THEN 1 ELSE 0 END) as optimized_count
FROM shipments s
LEFT JOIN items i ON s.id = i.shipment_id
WHERE s.shipment_no = 'ZIMUSNH21275749'
GROUP BY s.id;
```

### 3.5.2 获取优化统计
```sql
SELECT
    COUNT(*) as total_optimizations,
    AVG(similarity_score) as avg_similarity,
    COUNT(CASE WHEN risk_level = 'HIGH' THEN 1 END) as high_risk_count
FROM items
WHERE shipment_id = 123 AND is_optimized = TRUE;
```

### 3.5.3 清理过期缓存
```sql
DELETE FROM tax_rates
WHERE expires_at < NOW();
```

## 3.6 数据备份策略

### 每日备份
```bash
# PostgreSQL 备份
pg_dump -U postgres customs_db > backup_$(date +%Y%m%d).sql

# Redis 备份
redis-cli SAVE
cp /var/lib/redis/dump.rdb backup_redis_$(date +%Y%m%d).rdb
```

### 保留策略
- 每日备份保留 7 天
- 每周备份保留 4 周
- 每月备份保留 12 个月
