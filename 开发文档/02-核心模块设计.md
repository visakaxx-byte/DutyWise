# 核心模块设计

## 2.1 文档解析模块 (Document Parser)

### 2.1.1 功能描述
负责解析用户上传的Excel文档，提取原始数据。

### 2.1.2 输入
- 一"票"的 2-3 个 Excel 文件（.xlsx, .xls）
- 文件格式不固定

### 2.1.3 输出
```python
{
    "files": [
        {
            "filename": "04.03装柜信息(1).xlsx",
            "sheets": [
                {
                    "sheet_name": "Sheet1",
                    "headers": ["运单号码", "子单号码", "箱实重", ...],
                    "rows": [
                        {"运单号码": "FBA199P88KTF", "箱实重": 14.7, ...},
                        ...
                    ]
                }
            ]
        },
        ...
    ]
}
```

### 2.1.4 核心逻辑

```python
class DocumentParser:
    def parse_files(self, file_paths: List[str]) -> Dict:
        """解析多个Excel文件"""
        results = []

        for file_path in file_paths:
            # 1. 检测文件类型
            file_type = self.detect_file_type(file_path)

            # 2. 读取所有sheet
            sheets = self.read_all_sheets(file_path)

            # 3. 识别表头行
            for sheet in sheets:
                header_row = self.detect_header_row(sheet)
                data_rows = self.extract_data_rows(sheet, header_row)

                results.append({
                    "filename": file_path,
                    "sheet_name": sheet.name,
                    "headers": header_row,
                    "rows": data_rows
                })

        return {"files": results}
```

## 2.3 税率查询模块 (Tax Rate Crawler)

### 2.3.1 功能描述
从 codeflagai.com 查询商品的税率和认证要求。

### 2.3.2 技术方案
- 使用 Playwright 处理JS渲染
- Redis 缓存查询结果（7天）
- 反爬虫策略：随机延迟、轮换UA

### 2.3.3 返回数据
```python
{
    "hs_code_cn": "8481901000",

    "description_cn": "阀门垫圈件",
    "tax_rate": "Free",

```

## 2.4 HS编码优化模块 (HS Code Optimizer)

### 2.4.1 功能描述
从多个HS编码选项中，选择税率最低且品类相似的编码。

### 2.4.2 优化策略

#### 过滤条件
- ✅ 排除需要认证的
- ✅ 排除税率更高的
- ⚠️ 有反倾销的标注风险

#### 相似度计算
```
总分 = 关键词匹配(40%) + HS前缀匹配(30%) + 材质匹配(20%) + 用途匹配(10%)
```

#### 综合评分
```
最终得分 = 税率得分(60%) + 相似度得分(40%)
```

### 2.4.3 示例

**输入**：
- 原品名：阀门配件
- 原HS编码：8481901000
- 原税率：25%

**候选编码**：
| HS编码 | 描述 | 税率 | 相似度 | 综合得分 |
|--------|------|------|--------|---------|
| 8481900085 | 阀门垫圈件 | Free | 0.85 | 0.94 |
| 8481903000 | 其他旋塞 | 5% | 0.75 | 0.87 |
| 7326909000 | 其他钢铁制品 | 13% | 0.40 | 0.68 |

**输出**：选择 8481900085

## 2.5 文件生成模块 (File Generator)

### 2.5.1 功能描述
根据优化后的数据，填充清关.xlsx模板。

### 2.5.2 处理逻辑
1. 读取清关.xlsx模板
2. 定位数据起始行
3. 逐行填充数据
4. 处理缺失字段（留空或标记"待补充"）
5. 保存文件

### 2.5.3 代码示例
```python
class FileGenerator:
    def generate(self, optimized_data: List[Dict], template_path: str) -> str:
        """生成清关文件"""
        wb = openpyxl.load_workbook(template_path)
        ws = wb.active

        # 找到数据起始行（表头下一行）
        start_row = self.find_data_start_row(ws)

        # 填充数据
        for idx, item in enumerate(optimized_data):
            row_num = start_row + idx

            for col_name, value in item.items():
                col_idx = self.get_column_index(ws, col_name)
                if col_idx:
                    ws.cell(row_num, col_idx).value = value

                    # 缺失字段标记
                    if value is None:
                        ws.cell(row_num, col_idx).value = "待补充"
                        ws.cell(row_num, col_idx).font = Font(color="FF0000")

        # 保存
        output_path = f"清关_{datetime.now().strftime('%Y%m%d_%H%M%S')}.xlsx"
        wb.save(output_path)

        return output_path
```

## 2.6 日志模块 (Logger)

### 2.6.1 功能描述
记录所有操作，包括替换记录、冲突记录、字段映射记录。

### 2.6.2 日志格式（Excel）

**Sheet1: 替换日志**
| 原品名 | 原HS编码 | 原税率 | 新HS编码 | 新税率 | 替换原因 | 风险提示 |
|--------|---------|--------|---------|--------|---------|---------|
| 阀门配件 | 8481901000 | 25% | 8481900085 | Free | 税率更低 | ⚠️ 有反倾销标记 |

**Sheet2: 数据冲突日志**
| 字段 | 文档A的值 | 文档B的值 | 处理方式 |
|------|----------|----------|---------|
| 总重量 | 15650kg | 15800kg | 已空着，请手动填写 |

**Sheet3: 字段映射日志**
| 输入文档字段 | 映射到清关字段 | 置信度 |
|-------------|--------------|--------|
| "品名" | 中文品名 | 95% |

### 2.6.3 代码示例
```python
class Logger:
    def create_log_file(self, logs: Dict) -> str:
        """创建日志文件"""
        wb = Workbook()

        # Sheet1: 替换日志
        ws1 = wb.active
        ws1.title = "替换日志"
        ws1.append(["原品名", "原HS编码", "原税率", "新HS编码", "新税率", "替换原因", "风险提示"])
        for log in logs["optimization_logs"]:
            ws1.append([
                log["original_name"],
                log["original_hs_code"],
                log["original_tax_rate"],
                log["new_hs_code"],
                log["new_tax_rate"],
                log["reason"],
                log.get("risk_warning", "")
            ])

        # Sheet2: 数据冲突日志
        ws2 = wb.create_sheet("数据冲突日志")
        ws2.append(["字段", "文档A的值", "文档B的值", "处理方式"])
        for conflict in logs["conflicts"]:
            ws2.append([
                conflict["field"],
                conflict["value_a"],
                conflict["value_b"],
                "已空着，请手动填写"
            ])

        # Sheet3: 字段映射日志
        ws3 = wb.create_sheet("字段映射日志")
        ws3.append(["输入文档字段", "映射到清关字段", "置信度"])
        for mapping in logs["mapping_logs"]:
            ws3.append([
                mapping["source_field"],
                mapping["target_field"],
                f"{mapping['confidence']*100:.0f}%"
            ])

        output_path = f"日志_{datetime.now().strftime('%Y%m%d_%H%M%S')}.xlsx"
        wb.save(output_path)

        return output_path
```
